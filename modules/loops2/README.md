# Loops 2: Nested Loops, Looping Structures

## Objectives

- Nested Loops
- Using loops with lists and other data structures
- Block scope
- More about the range function
- Flow control with `continue` and `break`
- Handling exceptions with `try` and `except`

## Example code

### [nestedloops.py](./nestedloops.py)

A minimal nested loop: an outer loop and an inner loop printing each pair of loop variables

### [control.py](./control.py)

A review of Python control structures using a number entered by the user: `if`/`elif`/`else`, `while` loops, `for` loops with `range()`, looping through a list, and using `break` and `continue` to change the flow of a loop

### [exceptions.py](./exceptions.py)

Handling exceptions with `try`/`except`. A `safe_divide()` function catches a `ZeroDivisionError` and raises a `ValueError` with a clearer message, which the calling code then catches.
