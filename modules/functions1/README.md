# Functions

## Objectives

- Basic functions
- Writing user-defined functions
- Using built-in functions
- Parameters & arguments
- Return statements
- Multiple function outputs
- Function docstrings

## Example code

### [functionslidecode.py](./functionslidecode.py)

Code examples from the module slides: why functions are useful, defining and calling functions, parameters, positional and keyword arguments, default parameters, return values, returning several values (tuples, lists, and dictionaries), and docstrings

### [functionnotes.py](./functionnotes.py)

A longer set of notes that covers the same topics in more detail:

- Defining and calling functions
- Built-in functions and functions from the `math` module
- Parameters vs. arguments, and why the order of arguments matters
- Positional, keyword, and default arguments
- Return values, including functions that return `None`
- Using a return value in an expression or as an argument to another function
- Returning multiple values as a tuple, list, or dictionary

### [docstringnotes.py](./docstringnotes.py)

How to write docstrings: one-line and multi-line docstrings, documenting parameters (`Args`) and return values (`Returns`), several well-documented example functions, and viewing a docstring with `help()`

### [functions.py](./functions.py)

Short examples of functions with and without return values, functions that work with lists, and a `main()` function called with the `if __name__ == "__main__":` pattern
