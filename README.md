# csc101-intro-to-computing-with-python

Repo for CSC101 - Introduction to Computing with Python at CGCC

## Repository structure

- [assignments/](./assignments/) — Course assignments, organized into introductory exercises ([intro/](./assignments/intro/)), labs ([labs/](./assignments/labs/)), and larger projects ([projects/](./assignments/projects/)).
- [classexamples/](./classexamples/) — Code worked through live during in-person sections, organized by term.
- [code/](./code/) — Miscellaneous code not tied to a specific course module.
- [debugging/](./debugging/) — Debugging exercises: short programs with common errors to find and fix, starting with [syntax errors](./debugging/syntax/).
- [modules/](./modules/) — The core course material, organized by topic module: getting started, introduction to computers, the software development life cycle, variables, strings, lists/tuples/sets/dictionaries, conditionals, loops, functions, classes, file I/O, advanced topics, and data analysis.
- [otherexamples/](./otherexamples/) — Standalone example sets that supplement the notes, such as [helpermethods/](./otherexamples/helpermethods/).
- [resources/](./resources/) — Additional Python and computer-science reference material and documentation links.
