# Advanced Functions & Modules

## Objectives

- Importing built-in modules
- Default parameters & keyword arguments
- Variable-length argument lists
- Local, global, & nonlocal variable scope
- Lambda functions
- Error handling with `try`, `except`, `else`, `finally`, and `raise`

## Example code

### [overview.py](./overview.py)

An overview of the module topics:

- Different ways to import modules (`import`, `from ... import`, and `import ... as`)
- Using the `math`, `datetime`, and `random` modules
- Default parameters and keyword arguments
- Variable-length arguments with `*args` and `**kwargs`
- Variable scope with the `global` and `nonlocal` keywords
- Comparing a regular function with a `lambda`

### [advancedfunctions.py](./advancedfunctions.py)

Positional and keyword arguments, variable-length argument lists (`*nums`), and positional-only (`/`) and keyword-only (`*`) parameters

### [random_number.py](./random_number.py)

A number guessing game that uses the `random` module to pick a secret number and gives the player a limited number of guesses

### [mapfiltersorted.py](./mapfiltersorted.py)

Using `lambda` functions with `map()`, `filter()`, and `sorted()` (including sorting a list of dictionaries by a key)

### [errorhandling.py](./errorhandling.py)

A reference for error handling: basic `try`/`except`, catching more than one exception type, using `else` and `finally`, raising your own exceptions, and best practices for handling errors
