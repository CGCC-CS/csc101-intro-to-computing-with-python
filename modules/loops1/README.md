# Loops 1: For Loops & While Loops

## Objectives

- Loop fundamentals
- For loops

## Example code

### [whileloops.py](./whileloops.py)

A minimal `while` loop that keeps asking for input until the user types `quit`

### [looppatterns.py](./looppatterns.py)

Common `while` loop patterns:

- Counting up, counting down, and counting by other increments
- Adding up numbers (accumulator pattern)
- Input validation - asking again until the user enters a valid value
- Sentinel-controlled loops - repeating until a special value (like `-1`) is entered
- An infinite `while True` loop that exits with `break`

### [forloops.py](./forloops.py)

`for` loops over different kinds of data: `range()`, strings, lists, tuples, and dictionaries
