# Data Types, Variables, & Expressions

## Objectives

- Python data types
- Working with variables
- Operators
- Expressions
- Input & output
- Comments

## Example code

### [moduleinfo.py](./moduleinfo.py)

Code examples from the module introduction video

### [variables.py](./variables.py)

Introduces variables and constants, naming conventions (`snake_case` for variables, `UPPER_CASE` for constants), and reassigning a variable

### [datatypes.py](./datatypes.py)

[Video link](https://youtu.be/rLc8Mes-MTg) (3:23) Introduces the different built-in data types in Python (int, float, str, bool, list, tuple, dict, set, complex) with printed examples. Also shows that a variable can be reassigned to a value of a different type.

### [operator.py](./operator.py)

[Video link](https://youtu.be/bKY3fD2wczA) (2:49) Examples of using the arithmetic operators (+, -, *, /, //, %, **) and how they behave with numbers

### [expressions.py](./expressions.py)

Builds on operator.py by showing more complex formulas and compound assignment operators (+=, -=, *=, //=)

### [comparison.py](./comparison.py)

Introduces the comparison and logical operators (==, !=, <, >, <=, >=, and, or, not)

### [comments.py](./comments.py)

Demonstration of good documentation practices: clear naming, inline comments, and docstrings while doing a simple circle area calculation

### [inputoutput.py](./inputoutput.py)

Interact with the user: getting input with `input()`, converting it with `int()` and `float()`, and displaying results with `print()` and f-strings (plus the older `.format()` style)

### [ex1calculator.py](./ex1calculator.py)

Putting it all together: input, arithmetic, and output to create a simple calculator program

### [shoppingcart.py](./shoppingcart.py)

A capstone example: integrates variables, operators, input, and formatting into a practical program that generates a receipt. Also uses loops which we will cover later.
