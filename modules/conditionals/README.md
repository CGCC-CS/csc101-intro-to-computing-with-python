# Conditional Statements

## Objectives

- Conditional statements: `if`, `elif`, & `else`
- Using logical operators
- Nested conditionals
- Using conditionals to solve problems
- Debugging conditional logic

## Example code

### [moduleintro.py](./moduleintro.py)

Code examples from the module introduction video, showing the `and`, `or`, and `not` logical operators. Values are hard-coded so the program runs without user input.

### [conditionalslides.py](./conditionalslides.py)

Code examples from the module slides:

- Comparison operators and basic `if` statements
- `if`/`else` (temperature check, even/odd)
- `if`/`elif`/`else` (letter grades)
- The difference between several separate `if` statements and one `if`/`elif` chain
- Logical operators `and`, `or`, and `not`
- Nested conditionals
- Validating user input with `isdigit()`
- Debugging conditional logic with `print()` statements
